# Mon Parfum Boutique

Crie o projeto Mon Parfum Commerce.

O objetivo é desenvolver um e-commerce premium, elegante e funcional para a Mon Parfum.

A prioridade absoluta é:

funcionamento real

navegação sólida

fluxo completo de compra

estrutura limpa

arquitetura organizada

UX premium

O projeto deve ser construído com foco total em e-commerce.

A plataforma deve conter:

Website público

Home

Catálogo

Categorias

Página de produto

Busca

Carrinho

Checkout

Minha conta

Dashboard administrativo

Produtos

Categorias

Pedidos

Clientes

Estoque básico

Funcionalidades

autenticação

banco de dados real

upload de imagens

checkout funcional

integração com pagamento

criação de pedidos

webhooks

status de pedidos

Arquitetura

Utilize:

Next.js

TypeScript

Tailwind

PostgreSQL

Prisma

Stripe/Pagar.me

Objetivo principal

Criar um e-commerce sólido, limpo e funcional.

Toda funcionalidade deve funcionar de ponta a ponta.

Evite:

mocks desnecessários

páginas vazias

botões sem ação

rotas quebradas

Priorize profundidade e qualidade ao invés de quantidade de módulos.

O sistema deve parecer uma boutique premium de perfumaria de luxo.
